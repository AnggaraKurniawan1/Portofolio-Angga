# Portofolio Anggara Kurniawan

Website portofolio interaktif dan responsif dari **Anggara Kurniawan**, Sarjana Sistem Informasi dari **Institut Teknologi Kalimantan (ITK)** (IPK 3.63).

Dibuat menggunakan **HTML5, Tailwind CSS, React, dan Vite**, dilengkapi dengan dark/light mode switcher, studi kasus interaktif, showcase skill, dan integrasi tautan langsung.

## 💻 Menjalankan Secara Lokal

1. **Clone repositori:**
   ```bash
   git clone https://github.com/AnggaraKurniawan1/Portofolio-Angga.git
   cd Portofolio-Angga
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Jalankan development server:**
   ```bash
   npm run dev
   ```
   Akses di browser: `http://localhost:5173`

4. **Build untuk production:**
   ```bash
   npm run build
   ```
   Hasil build siap saji akan berada di folder `dist/`.
